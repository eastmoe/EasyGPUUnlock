# Sources and modifications

EasyGPUUnlock is GPL-2.0-only. License text is in LICENSE and licenses/GPL-2.0.txt.

- gpu-unlock-ada, local revision `d28c485418c3d9d034cd4bac19200bc33dd3453b`, https://github.com/JustAResearcher/gpu-unlock-ada. The separate Ada engine, helpers, pin tables, admission list, deterministic asset generators and host tests are retained in vendor/gpu-unlock-ada/, vendor/ada-firmware-tools/ and tests/ada/. Published AD102-family four-PLM payload provenance is TOTORONG/AD103_win_unlocker revision `51df9c17ec89eb8486df52cc9079dde4bd1f9974`; see licenses/ADA-FIRMWARE-NOTICE.md and the pinned Ada manifest. Windows changes: byte-addressable BAR pointer, firmware-start lifetime notification, cached pre/post-FLR readout and validated handover notification before MSE restore. Symbols are namespaced at compile time to retain the existing Ampere engine independently. Test-only changes adapt includes, errno, GCC attributes and snapshot assertions for MSVC. All Ada marker, HALT, permission, signature, pre/post-FLR effective-rate and retention guards remain active. Upstream Linux hardware reports are not presented as EasyGPUUnlock Windows hardware tests.

- gpu-unlock, local revision `af28cbbfd3d922a659227ecfb7369adfd924cf03`, https://github.com/Zagitta/gpu-unlock. Retained `unlock_610`, `prep_610`, `layout_610`, `vbios_610`, `gfw_eval` and diagnostic sources, firmware generators, pinned artifact manifest, and host test vectors. Vendor changes: BAR pointer becomes `u8 *` for standard C byte arithmetic; notifications record the firmware DMA ownership boundary and cache the verified handover registers before Windows restores PCI memory decode. The host-only test shim implements the ownership notification as a no-op and asserts the handover snapshot values / count. The transaction's cold-state guards, signatures, selectors, and containment checks are retained. The retained test shim uses Linux errno numbers on Windows, omits GCC's format attribute, and updates the source include path / macro guard for MSVC.
- cmp170hx-windows-driver, local revision `a7a8b794d0caf8d543db68dcb744b051f996124f`. Windows KMDF exclusive PnP ownership, raw BAR0 to translated-resource matching, HAL common-buffer lifetime, administrative interface ACL, and synchronous `GUID_DEVICE_RESET_INTERFACE_STANDARD` model informed the independent Windows implementation. Its GA100 firmware/memory algorithm is not used for GeForce.
- Windows-GPU-UNLOCK: retained standalone SHA-256 implementation and pinned five-file firmware asset manifest. Only the SHA-256 header's platform types/includes are adapted to WDK. Original project license retained as licenses/Windows-GPU-UNLOCK.txt.
- NVIDIA 610.43.03 firmware is extracted from the pinned NVIDIA/CachyOS inputs listed in vendor/firmware-tools/artifacts-610.43.03.json. The unmodified firmware has its own NVIDIA license, included with the binary distribution as licenses/NVIDIA-Driver.txt. Other reference notices are in licenses/.

Source retrieval and asset extraction run only at build time; no vendor scripts execute with kernel privilege. The binary kit includes corresponding source in source/. The generated firmware hashes are checked both while preparing the kit and in the kernel before use.
